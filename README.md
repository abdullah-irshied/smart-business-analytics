# Smart Business Analytics & Prediction Platform
منصة التحليل والتنبؤ التجاري الذكية

## نبذة عن المشروع
مشروع تدريب ميداني فردي لتحليل بيانات المبيعات والعملاء
وتقسيم العملاء إلى فئات، والتنبؤ بالمبيعات الأسبوعية
وعرض النتائج في تطبيق تفاعلي

## حالة المشروع
المشروع حاليًا في مرحلة إعداد متطلبات الأسبوع الأول
تم تحديد الهدف والنطاق ومؤشرات الأداء وخطة تقييم النماذج
وتوثيق مسؤولية التنفيذ الفردي
لم يبدأ تنفيذ تحليل البيانات أو النماذج أو التطبيق بعد

## تنظيم المجلدات
- docs: وثائق المشروع ومتطلباته
- data: البيانات الأصلية والبيانات الناتجة عن المعالجة
- notebooks: دفاتر Jupyter الخاصة بالتحليل والنماذج
- sql: ملفات تصميم قاعدة البيانات والاستعلامات
- app: ملفات التطبيق التفاعلي
